# Breast Cancer MLOps Project

An end-to-end machine learning and MLOps project for breast cancer classification using the Scikit-learn Breast Cancer dataset.

## Objective

The objective of this project is to demonstrate an end-to-end machine learning lifecycle including:

- Data ingestion
- Data preprocessing
- Model training
- Model evaluation
- Model serialization
- Experiment tracking
- Data and pipeline versioning
- Automated testing
- Model serving
- Containerization
- Continuous integration

## Machine Learning Model

The project uses:

- StandardScaler
- Logistic Regression

The preprocessing and model are combined using a Scikit-learn Pipeline.

## MLOps Tools

- Git / GitHub
- DVC
- MLflow
- pytest
- FastAPI
- Docker
- GitHub Actions

## Project Pipeline

Data Ingestion
→ Preprocessing
→ Model Training
→ Evaluation
